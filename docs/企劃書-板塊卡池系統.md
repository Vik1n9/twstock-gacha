## 1. 卡池系統概述

### 1.1 卡池定義

卡池指一組可被抽出的股票卡片集合。玩家在抽卡前可先選擇要抽取的卡池。不同卡池會影響可抽出的股票範圍、卡面主題、抽卡演出與營運活動設計。

### 1.2 卡池與稀有度關係

卡片稀有度仍由該股票最近 30 個交易日漲跌幅決定，不因卡池不同而改變。

```text
稀有度判定仍依照：
過去30日漲跌幅 0%～未滿5%：C
過去30日漲跌幅 5%～未滿15%：R
過去30日漲跌幅 15%～未滿30%：SR
過去30日漲跌幅 30%以上：SSR

下跌卡依照跌幅絕對值採用相同門檻。
```

### 1.3 卡池功能

卡池系統提供以下功能：

1. 讓玩家選擇抽取範圍。
2. 以台股板塊建立主題卡池。
3. 提供每日精選卡池。
4. 提供後續活動卡池擴充。
5. 提供板塊主題抽卡特效。
6. 提供圖鑑與收集系統分類。

## 2. 卡池類型

### 2.1 全市場卡池

全市場卡池包含所有符合抽卡條件之台股股票。

特性：

- 永久開放。
- 股票數量最大。
- 稀有度分布最完整。
- 適合一般抽卡與新手引導。

### 2.2 板塊卡池

板塊卡池依台股板塊或產業主題分類，只包含屬於該板塊標籤的股票。

特性：

- 玩家可指定板塊抽卡。
- 卡池範圍較小。
- 板塊主題視覺較強。
- 可配合市場話題開放。

### 2.3 每日精選板塊卡池

系統每日依板塊表現自動選出數個板塊池。

特性：

- 每日更新。
- 可選出強勢板塊池與弱勢板塊池。
- 可作為首頁推薦卡池。
- 不影響玩家手動選擇其他板塊池。

### 2.4 主題活動卡池

後續擴充用卡池，可由營運人工設定。

可能形式：

- 半導體週。
- 航運週。
- 金融週。
- 生技週。
- 綠能週。
- 強勢板塊限時池。
- 跌勢主題池。

## 3. 台股板塊分類設計

### 3.1 分類原則

板塊分類採用「產業分類」與「市場主題標籤」混合設計。

原因如下：

1. 台股部分個股業務跨足多個產業。
2. 市場話題常以主題板塊呈現，例如 AI、半導體、綠能、航運。
3. 遊戲卡池需要明確、易讀、具視覺辨識度的板塊標籤。
4. 單一股票可同時屬於多個板塊，但抽卡時以卡池篩選條件為主。

### 3.2 板塊標籤規則

每檔股票可設定：

| 欄位   | 說明                  |
| ---- | ------------------- |
| 主板塊  | 股票最主要歸屬板塊，至少 1 個。   |
| 副板塊  | 其他相關板塊，最多建議 3 個。    |
| 活動標籤 | 營運臨時加入之標籤，可隨時啟用或停用。 |

卡池篩選規則：

```text
只要股票具有該板塊之任一標籤，即可進入該板塊卡池。
```

## 5. 板塊卡池生成規則

### 5.1 每日卡池生成時點

每日收盤資料確認後，系統生成當日卡池快照。

建議流程：

```text
1. 取得最近完整交易日收盤資料。
2. 計算每檔股票昨日漲跌幅。
3. 計算每檔股票過去30個交易日漲跌幅。
4. 判定每檔股票稀有度與漲跌方向。
5. 依板塊標籤產生板塊卡池。
6. 計算各板塊池統計數據。
7. 決定開放或隱藏板塊池。
```

### 5.2 板塊池組成條件

一個板塊池需由同時符合以下條件的股票組成：

1. 屬於該板塊標籤。
2. 具有有效股票代號與名稱。
3. 具有最近完整交易日收盤價。
4. 可計算過去 30 個交易日漲跌幅。
5. 非停牌、非暫停交易。
6. 資料無異常。
7. 符合原抽卡池納入規則。

### 5.3 板塊池開放門檻

建議每個板塊池需符合以下條件才可開放：

| 條件      | 建議值    |
| ------- | ------:|
| 最少可抽股票數 | 30 檔   |
| 上漲方向股票數 | 至少 1 檔 |
| 下跌方向股票數 | 至少 1 檔 |
| 資料完整率   | 100%   |

若未達開放門檻，該板塊池於當日隱藏，並顯示「今日未開放」或「資料不足」。

### 5.4 單方向板塊池處理

若某板塊池內全部股票均為上漲或全部為下跌，可採用以下兩種方案：

#### 方案 A：不開放

首版建議採用。

原因：

- 避免玩家誤解機率。
- 避免方向概率過度極端。
- 維持抽卡方向平衡。

#### 方案 B：開放為單方向板塊池

若營運希望強化市場真實感，可開放單方向板塊池。

規則：

```text
卡池名稱後方標註單方向狀態。
例如：半導體池：本日全上漲
抽卡方向概率為100%上漲。
```

此方案需於機率頁面明確揭露。

## 6. 板塊強度計算

### 6.1 板塊昨日強度

用於呈現該板塊最近一個完整交易日的表現。

```text
板塊昨日強度 = 板塊內所有可抽股票昨日漲跌幅的中位數
```

### 6.2 板塊 30 日強度

用於呈現該板塊近期趨勢，也可作為每日精選池排序依據。

```text
板塊30日強度 = 板塊內所有可抽股票過去30日漲跌幅的中位數
```

### 6.3 使用中位數原因

建議使用中位數而非平均數，原因如下：

1. 避免單一極端股票過度影響板塊強度。
2. 較能代表板塊內多數股票狀態。
3. 較適合用於首頁視覺與精選池排序。

## 7. 每日精選板塊池

### 7.1 精選池目的

每日精選池用於提高每日變化性，並讓玩家關注當日市場話題。

### 7.2 精選池產生規則

每日系統可自動產生以下精選池：

| 精選池類型 | 產生方式                       |
| ----- | -------------------------- |
| 強勢板塊池 | 依板塊30日強度由高至低排序，取前 2 至 3 個。 |
| 弱勢板塊池 | 依板塊30日強度由低至高排序，取前 1 至 2 個。 |
| 話題板塊池 | 由營運人工指定。                   |

### 7.3 精選池顯示內容

每日精選池需顯示：

- 板塊名稱。
- 精選原因。
- 板塊昨日強度。
- 板塊 30 日強度。
- 板塊池股票數。
- 稀有度分布。
- 抽卡入口。

### 7.4 精選池範例

```text
今日強勢板塊：半導體
板塊30日強度：+18.4%
板塊股票數：72
開放狀態：開放
說明：近30個交易日板塊表現強勢。
```

```text
今日弱勢板塊：航運物流
板塊30日強度：-12.6%
板塊股票數：41
開放狀態：開放
說明：近30個交易日板塊表現偏弱。
```

## 8. 板塊卡池抽卡規則

### 8.1 抽卡前選擇卡池

玩家抽卡前需先選擇卡池。

可選擇：

```text
1. 全市場池
2. 任一開放之板塊池
3. 每日精選池
```

### 8.2 單抽規則

單抽只從玩家目前選擇的卡池中抽出 1 張卡片。

### 8.3 十連抽規則

十連抽只從玩家目前選擇的卡池中抽出 10 張卡片。

十連抽之 10 次抽選預設為獨立抽選。

### 8.4 板塊池不影響稀有度判定

板塊池不會改變稀有度門檻。

```text
無論抽哪個板塊池：
漲幅30%以上仍為上漲SSR。
跌幅30%以上仍為下跌SSR。
```

## 9. 板塊卡池機率設計

### 9.1 全市場池機率

全市場池維持原設計：

| 方向  | 機率     |
| --- | ------:|
| 上漲  | 50.00% |
| 下跌  | 50.00% |

| 稀有度 | 方向內機率  |
| --- | ------:|
| C   | 80.00% |
| R   | 15.00% |
| SR  | 4.00%  |
| SSR | 1.00%  |

---

### 9.2 板塊池方向機率

板塊池建議採用動態方向機率，以符合該板塊實際股票分布。

```text
板塊池上漲機率 = 板塊池內上漲股票數 ÷ 板塊池內可抽股票總數
板塊池下跌機率 = 板塊池內下跌股票數 ÷ 板塊池內可抽股票總數
```

### 9.3 板塊池方向機率範例

假設半導體池當日共有 100 檔可抽股票：

| 項目   | 數量  |
| ---- | ---:|
| 上漲股票 | 70  |
| 下跌股票 | 30  |
| 總數   | 100 |

則半導體池方向機率為：

| 方向  | 機率     |
| --- | ------:|
| 上漲  | 70.00% |
| 下跌  | 30.00% |

### 9.4 板塊池稀有度機率

板塊池內稀有度仍採用以下目標機率：

| 稀有度 | 方向內機率  |
| --- | ------:|
| C   | 80.00% |
| R   | 15.00% |
| SR  | 4.00%  |
| SSR | 1.00%  |

### 9.5 板塊池實際機率說明

板塊池實際機率可能因以下因素而產生微幅差異：

1. 該板塊內某稀有度無股票。
2. 該板塊內某方向股票不足。
3. 空池降級規則觸發。
4. 單方向板塊池開放。
5. 板塊池股票數量過少。

因此機率頁面需加註：

```text
板塊卡池之方向機率依當日該板塊內可抽股票之實際漲跌分布計算。
若指定稀有度於該板塊池中無可抽股票，系統將依空池處理規則調整。
實際機率以當日卡池快照與系統公告為準。
```

## 10. 板塊池空池處理規則

### 10.1 抽卡前檢查

玩家選擇板塊池後，前端應先檢查該池是否開放。

若未開放，不得進入抽卡。

### 10.2 抽卡中稀有度空池

若抽中某方向與稀有度，但板塊池內無符合股票，處理順序如下：

```text
1. 維持原方向。
2. 稀有度降低一級。
3. 若仍無股票，再降低一級。
4. 直至抽出可抽卡片。
```

### 10.3 抽卡中方向空池

板塊池方向機率應依實際股票分布計算，因此不應抽到完全無股票之方向。

若因資料異常導致方向空池，系統應重新抽取方向，並記錄異常。

### 10.4 不自動退回全市場池

為維持玩家對板塊池的預期，板塊池抽卡不應自動退回全市場池。

若板塊池無法抽出卡片，應回傳錯誤並提示：

```text
此板塊卡池目前資料不足，請選擇其他卡池。
```

若抽卡行為消耗次數或資源，需退還該次消耗。

## 13. 板塊卡池抽卡特效

## 17. 抽卡流程更新

### 17.1 板塊池抽卡偽代碼

```text
function drawFromPool(pool):
    if not pool.isOpen:
        return error

    direction = rollDirectionByPool(pool)
    rarity = rollRarity()

    candidatePool = filter(pool.stocks, direction, rarity)

    while candidatePool is empty and rarity > C:
        rarity = downgradeRarity(rarity)
        candidatePool = filter(pool.stocks, direction, rarity)

    if candidatePool is empty:
        return error

    stock = selectStockByWeight(candidatePool)

    return createCard(stock, pool, direction, rarity)
```

### 17.2 板塊池方向機率偽代碼

```text
function rollDirectionByPool(pool):
    upCount = count(pool.stocks where direction = UP)
    downCount = count(pool.stocks where direction = DOWN)

    totalCount = upCount + downCount

    if totalCount == 0:
        return error

    upRate = upCount / totalCount
    downRate = downCount / totalCount

    return randomByRates(upRate, downRate)
```

## 18. 機率揭露頁面更新

機率頁面需新增板塊卡池說明。

### 18.1 必載內容

1. 全市場池機率。
2. 板塊池方向機率計算方式。
3. 板塊池稀有度目標機率。
4. 板塊池空池處理規則。
5. 每日精選池生成方式。
6. 板塊池開放門檻。
7. 當日各板塊池股票數與方向分布。

### 18.2 揭露文案範例

```text
全市場卡池之上漲與下跌方向機率各為50%。
板塊卡池之上漲與下跌方向機率，依當日該板塊內可抽股票之實際漲跌分布計算。

板塊卡池內稀有度目標機率如下：
C級：80%
R級：15%
SR級：4%
SSR級：1%

若抽中之稀有度於該板塊卡池中無可抽股票，系統將依空池處理規則降低稀有度後重新抽取。
```

## 21. 風險與對策

| 風險         | 影響        | 對策                |
| ---------- | --------- | ----------------- |
| 板塊分類不準確    | 玩家誤解卡片歸屬  | 提供主副板塊、人工審核、後台修正。 |
| 某板塊股票數不足   | 無法開放板塊池   | 設定最低股票數，隱藏不足板塊。   |
| 板塊池稀有度分布極端 | 玩家抽不到高稀有卡 | 機率頁揭露，並顯示稀有度分布。   |
| 動態方向概率造成誤解 | 玩家認為機率不透明 | 顯示當日板塊池上漲與下跌股票數。  |
| 熱門板塊卡池過度集中 | 其他板塊使用率低  | 提供每日精選池與活動池。      |
| 股票同時屬於多板塊  | 卡池重疊      | 以多標籤設計處理，不影響抽卡結果。 |
| 板塊主題特效過多   | 效能下降      | 提供低特效模式與資源延遲載入。   |

## 23. 結論

加入板塊卡池後，遊戲仍維持單純抽卡玩法，但抽卡行為從單一全市場池擴展為可選擇的台股板塊池。

板塊卡池之核心規則如下：

1. 稀有度仍由個股過去 30 日漲跌幅決定。
2. 板塊僅決定可抽股票範圍與主題演出。
3. 全市場池使用固定方向機率。
4. 板塊池方向機率依池內實際漲跌分布計算。
5. 板塊池稀有度機率與全市場池目標機率一致。
6. 板塊池需達到最低股票數才可開放。
7. 每日精選池可依板塊強度自動生成。
8. 抽卡特效需結合板塊主題，強化視覺辨識度。

此機制可使遊戲在維持簡單抽卡體驗的同時，增加板塊收集、主題視覺、每日變化與後續營運活動空間。
